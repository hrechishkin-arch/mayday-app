Mayday — набросок приложения (чистое время)

Открыть на телефоне:
https://hrechishkin-arch.github.io/na-kyiv-mayday/app/

Локально: откройте app/index.html в браузере.

Вкладки: Чистота / Ежедневник / Связь
Дата хранится только на телефоне.
Это не магазин App Store — страница «Добавить на экран Домой».

Как сделать отдельный проект:
1. Создайте новый репозиторий на GitHub, например mayday-app
2. Залейте папку app/ в корень репозитория
3. Включите GitHub Pages (branch main, folder /)
4. В Grok создайте новый проект и вставьте ссылку на этот репозиторий
